# first-pr-demo

Mein erstes GitHub Repository

## Über dieses Projekt

Dieses Repository wurde erstellt, um den GitHub-Workflow zu lernen — inklusive Pull Requests, Branches und Commits.

## Was ist ein Pull Request?

Ein Pull Request (PR) ist ein Vorschlag, Änderungen in ein Repository einzufügen. Andere können den Code prüfen, bevor er zusammengeführt wird.
